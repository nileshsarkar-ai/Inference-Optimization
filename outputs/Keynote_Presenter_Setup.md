# Private presenter notes with Keynote and HDMI

The PPT stores the speaking script in each slide's native presenter-notes area. It is separate from the visible slide. Display configuration determines what the audience sees. Notes remain readable to anyone who receives and opens the presentation file.

All 22 native presenter notes were verified after import into Keynote on this Mac. The exported audience slides excluded the notes, and all 22 slide images were inspected. The physical HDMI setup still needs the classroom check below.

## HDMI projector or external screen

1. Connect HDMI and leave the MacBook open.
2. Open **Apple menu > System Settings > Displays**. Select the external display and choose **Extended display** from **Use as**. Turn mirroring off. [Apple display setup](https://support.apple.com/guide/mac-help/extend-mirror-mac-desktop-multiple-displays-mchlb5f905a1/mac).
3. Open `Inference_Optimization_Final.pptx` in Keynote. Choose **View > Show Presenter Notes** to read the imported script while preparing.
4. Choose **Play > In Fullscreen**, then start the slideshow. The projector should show the audience slide and the MacBook should show the presenter display.
5. If they are reversed, press **X** to swap displays. In the presenter display's options, enable **Presenter Notes** and adjust the notes text size.
6. Check the physical projector before beginning: it should show only the slide, with no script, timer or upcoming slide. [Apple's separate-display instructions](https://support.apple.com/en-mide/guide/keynote/tana4da2681/mac).

Mirroring sends the same image to both screens, so it cannot provide private notes on the MacBook. Do not show the editor or the presenter display on the projector.

## If the room also uses Zoom, Meet or another meeting app

Share the audience slideshow window or the external slideshow display. Keep the presenter display outside the shared area. In **Keynote > Settings > Slideshow**, leave **Show presenter display window in other applications** unchecked. Apple notes that some meeting apps still capture a presenter window when it lies inside the shared screen area. Check the meeting's sharing preview as well as the projector. [Apple's conferencing instructions](https://support.apple.com/en-us/102025).

The file does not automatically configure HDMI displays. The final check must happen with the actual classroom projector connected.
